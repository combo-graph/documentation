## What is Combo Graph

The main idea behind this plugin is to try to cut down iteration times as much as possible when designing and prototyping a new combat system / combos.

It comes with a custom editor / graph for a Gameplay Ability with state machine like capabilities to define combo strings and link montages / sequences together.


***Main Features***


<Cards>
  <Card title="Asset Editor">
    Highly customized Blueprint Editor with State Machine graph and Persona viewport / preview 

    Persona = Animation related goodies used in Anim BP and Anim Assets.
  </Card>

  <Card title="Sequences and Montages">
    Can use sequence or montages.

    If using a sequence, the montages are dynamically created before going through the play montage task.
  </Card>

  <Card title="Enhanced Input Transitions">
    Can define transition with Enhanced input actions, and have them displayed with keyboard or gamepad icons in the graph.
  </Card>

  <Card title="Animation State Auto Setup">
    Has an "auto setup" mechanism for [animation notify states](https://dev.epicgames.com/documentation/unreal-engine/animation-notifies-in-unreal-engine#notifystate) so that you don't have to edit each and every montages to setup the notify states
    you need (combo window and collision traces for instance).

    **But** still have the possibility to define Notifies in anim assets. The auto setup only takes place if the anim asset doesn't have the corresponding ANS.
  </Card>

  <Card title="Gameplay Effect Containers">
    Can define Gameplay Effect cost and effect containers to apply (for instance for damage) for each node.
  </Card>

  <Card title="Fallback mechanism for no GAS setup">
    Non GAS users can fallback to Unreal's Damage System for effect containers, and use a gameplay task in Character or Controller Blueprint to kick off combos.
  </Card>

  <Card title="Soft references">
    Montages / Sequences / Icons and VFX / SFX assets all using soft object references and handled in cpp (so that the abilities or characters using them doesn't explode in size)
  </Card>

  <Card title="Replication">
    Replicated and Multiplayer ready
  </Card>
</Cards>
